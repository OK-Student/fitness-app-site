Privacy Policy

Effective November 25, 2026.

Fitness App is a personal tool used by one person, its owner. This policy covers the data it reads from Google.

What it reads

With the owner's consent through Google sign-in, the app reads, read-only, the owner's Google Health data: sleep, heart rate, heart-rate variability, resting heart rate, blood oxygen, breathing rate, skin temperature and steps.

How the data is used

The data is used only to show the owner's own recovery and sleep dashboard and training suggestions. It is never used for advertising and never sold.

Where it is stored

Data is stored in a local database on the owner's own computer. It is not uploaded to any other server and is not shared with anyone. The sign-in token is stored in a local file readable only by the owner's user account.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local database removes all stored data.
